# Security policy / Politique de sécurité

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report vulnerabilities privately, either:

- by e-mail to **coucou@contextetech.com** (subject: `[SECURITY]`), or
- through GitHub's private reporting: *Security → Report a vulnerability* on this repository.

Include a description, the affected version or URL, steps to reproduce and, if possible, a proof of concept.

We acknowledge reports within **7 days**, aim to provide a fix or mitigation within **30 days**, and credit reporters in the release notes unless they prefer to stay anonymous.

## Supported versions

Only the latest release of the v1 branch (`main`) receives security fixes.

---

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique**. Écrivez à **coucou@contextetech.com** (objet : `[SECURITY]`) ou utilisez le signalement privé de GitHub. Réponse sous 7 jours, correctif visé sous 30 jours.
