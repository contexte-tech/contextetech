# Changelog

All notable changes are documented here. Versions follow [Semantic Versioning](https://semver.org).

## [1.0.1] - 2026-09-27

### Added
- `SECURITY.md` (private vulnerability reporting), this changelog.
- Automated tests (pytest) and continuous integration (GitHub Actions), linting with ruff.
- `TRADEMARKS.md`: names, logos and visuals are excluded from the AGPL-3.0; attribution to ContexteTech required in the legal notice.

### Changed
- Neutral default name ("Mon nom") and visuals; logos, images and the initial catalogue removed from the repository.

### Security
- No known vulnerabilities fixed in this release.

## [1.0.0] - 2026-09-27

First public release (AGPL-3.0).

### Added
- Catalogue of 11 LLM resource types (contexts, prompts, datasets, LoRA, MCP servers, models, agents, skills, evaluations, RAG, harnesses) with export to each tool's format.
- "Tested on" results per model and risk level for MCP servers and harnesses.
- Accounts with Argon2id password hashing, e-mail login alerts and password reset.
- Five-language interface (FR, EN, ES, DE, IT).

### Security
- No known vulnerabilities fixed in this release.
